# 线框库

> 用于 Phase 3。按页型查，不要从零画。

---

## 怎么用

1. 先列**内容清单**：这页要承载的信息按重要性排序，标出"必须首屏可见"
2. 从下表找最接近的页型
3. 出 2–3 个变体线框（不是直接用下面的），每个附一句布局概念 + 一句取舍
4. 给出推荐 + 理由
5. 用户确认后才渲染合成页

## 线框必须标注什么

每个线框旁边写这四行，否则等于没画：

```
内容最大宽  1120px
对齐轴      左对齐（标题与正文同轴）
栅格        12 列 / 24px 沟
首屏密度    3 个区块，其中 1 个含核心指标
```

---

## 通用原则

| 原则 | 说明 |
|---|---|
| 一个页面一个主任务 | 首屏只能有一个"这是干什么的"的答案 |
| 阅读顺序 = 信息优先级 | 线框里元素的位置就是它的优先级，不是装饰 |
| 左对齐优先 | 居中适合 < 3 行的短内容；正文、表单、设置一律左对齐 |
| 行长 < 80 字符 | 中文 30–40 字。超过就加栏或不并排 |
| 留白不是空白 | 组间留白是分组的唯一手段时，别再加分割线 |

## 页型

### 1. 仪表盘（Operate）

内容：核心指标 + 趋势 + 明细。

```
┌────────────────────────────────────────────────────────┐
│  标题                           [时间范围 ▾] [操作]     │
├────────────────────────────────────────────────────────┤
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐   │
│ │ 指标 A   │ │ 指标 B   │ │ 指标 C   │ │ 指标 D   │   │
│ │ 数值     │ │ 数值     │ │ 数值     │ │ 数值     │   │
│ │ 环比 ↑   │ │ 环比 ↓   │ │ 环比 —   │ │ 环比 ↑   │   │
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘   │
│                                                        │
│ ┌──────────────────────────┐ ┌──────────────────────┐ │
│ │ 趋势图                    │ │ 分布 / 排行           │ │
│ │                          │ │                      │ │
│ └──────────────────────────┘ └──────────────────────┘ │
│                                                        │
│ ┌────────────────────────────────────────────────────┐ │
│ │ 明细表                                             │ │
│ └────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────┘
```

**取舍**：指标卡等宽 vs 按重要性不等宽。等宽好看但抹平优先级；不等宽需要定宽比例（如 2:1:1:1）。

**首屏必须有**：核心指标 + 时间上下文。趋势图可以折到第二屏。

---

### 2. 列表 / 表格工作区（Operate）

内容：可筛选的对象集合 + 批量操作。

```
┌────────────────────────────────────────────────────────┐
│  标题                              [新建]              │
├────────────────────────────────────────────────────────┤
│  [搜索            ] [筛选 ▾] [排序 ▾]                  │
├────────────────────────────────────────────────────────┤
│  ☐  名称           状态      负责人     更新于          │
│  ──────────────────────────────────────────────────    │
│  ☐  …              …         …          …             │
│  ☐  …              …         …          …             │
├────────────────────────────────────────────────────────┤
│  已选 2 项            [批量操作]     ‹ 1 2 3 ›         │
└────────────────────────────────────────────────────────┘
```

**取舍**：筛选条常驻 vs 收进弹层。常驻占一行但可发现；弹层省空间但用户不知道有筛选。

**规则**：批量操作条**只在有选中项时出现**，不要常驻灰着。

---

### 3. 落地页（Persuade）

内容：一个主张 + 证据 + 行动。

```
┌────────────────────────────────────────────────────────┐
│  导航                                                   │
├────────────────────────────────────────────────────────┤
│                                                        │
│        主标题（1–2 行，占满宽度但不换行）                │
│        副标题（1 行，解释给谁用）                        │
│        [ 主行动 ]  [ 次要行动 ]                          │
│                                                        │
│        ┌──────────────────────────────┐                │
│        │ 产品截图 / 演示 / 关键视觉      │                │
│        └──────────────────────────────┘                │
├────────────────────────────────────────────────────────┤
│  证据区：3 个论据 / 客户 / 数据                          │
├────────────────────────────────────────────────────────┤
│  次行动区                                               │
└────────────────────────────────────────────────────────┘
```

**取舍**：主标题居中 vs 左对齐。居中更像"活动页"，左对齐更像"产品"。按品牌调性选。

**反模式**：主标题下面接一个"功能三宫格"——那是模板，不是主张。

---

### 4. 文档 / 长文（Read）

内容：可跳读的层级化正文。

```
┌──────────┬─────────────────────────────────────────────┐
│ 侧栏目录 │  标题                                        │
│          │  ─────────────────────────────────          │
│  一级    │  正文（行长 < 80 字符）                       │
│    二级  │                                             │
│    二级  │  ## 小节                                     │
│  一级    │  正文                                        │
│          │                                             │
│          │  ```代码块```                                │
│          │                                             │
│          │  ┌─ 提示框 ─────────────────┐                │
│          │  └──────────────────────────┘                │
└──────────┴─────────────────────────────────────────────┘
```

**取舍**：侧栏常驻 vs 折叠。文档站点常驻；产品内嵌文档折叠。

**规则**：正文列宽固定（如 680px），侧栏宽度变化不影响正文——否则阅读时行长会跳。

---

### 5. 设置页（Operate）

见 `references/rules/05-settings-surface.md`。核心：左名右控件、无外层卡片、组间大留白、删除独立成组。

---

### 6. 表单页（Operate）

见 `references/rules/06-form-layout.md`。核心：标签在上、输入全宽、单列。

**单列 vs 双列**：单列永远对。只有在"姓名 / 姓氏"这种天然成对且都很短时才拆两列，且拆了之后仍要保证移动端回到单列。

---

### 7. AI 对话（Operate / Experience）

内容：消息流 + 输入区 + 可选侧栏。

```
┌──────────┬─────────────────────────────────────────────┐
│ 会话列表 │  消息流（最大宽 720px，居中或左对齐）         │
│          │                                             │
│  ● 当前  │  ┌─ 用户消息 ──────────────────┐            │
│    …     │  └──────────────────────────────┘            │
│    …     │  ┌─ 助手消息 ────────────────────────────┐   │
│          │  │ ▸ 思考过程（可展开）                   │   │
│          │  │ 正文…（流式，30ms 错峰模糊对焦）       │   │
│          │  │ 工具调用条                            │   │
│          │  └───────────────────────────────────────┘   │
│          │  ┌───────────────────────────────────────┐   │
│          │  │ 输入区（多行，全宽，发送键在右下）       │   │
│          │  └───────────────────────────────────────┘   │
└──────────┴─────────────────────────────────────────────┘
```

**取舍**：消息居中 vs 左对齐。居中适合纯对话产品；左对齐适合对话嵌在工作区里。

**规则**：输入区必须固定在底部，不随消息流滚动。消息流滚动时输入区不缩。

---

### 8. 详情页（Operate）

内容：一个对象 + 它的属性和相关操作。

```
┌────────────────────────────────────────────────────────┐
│  ‹ 返回    对象名称              [次要操作] [主操作]    │
├────────────────────────────────────────────────────────┤
│  ┌──────────────────────────┐ ┌──────────────────────┐ │
│  │ 主要内容                 │ │ 属性面板             │ │
│  │                          │ │ 状态      …          │ │
│  │                          │ │ 创建于    …          │ │
│  │                          │ │ 负责人    …          │ │
│  └──────────────────────────┘ └──────────────────────┘ │
│                                                        │
│  ┌────────────────────────────────────────────────────┐ │
│  │ 关联内容 / 历史 / 评论区                            │ │
│  └────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────┘
```

**取舍**：属性面板右置 vs 顶部横排。右置能放更多字段且不挤压主内容；横排省纵向空间但字段数受限（≤4）。

## 响应式降级

| 断点 | 布局变化 |
|---|---|
| ≥ 1200 | 完整布局，侧栏常驻 |
| 768–1199 | 侧栏折叠为图标；双栏变单栏 |
| < 768 | 全部单列；表格横向滚动或卡片化；操作收进底部固定条 |

**降级原则**：先降结构，再降字号。不要把 12 列挤成 4 列——直接改成单列列表。

---

## 反模式

| 反模式 | 为什么错 |
|---|---|
| 每页都从三宫格开始 | 内容不是"三个并列功能"，被硬塞进格子 |
| 所有页面同一个布局 | 落地页和设置页的阅读任务完全不同 |
| 线框里画最终视觉 | 会让人讨论阴影和圆角，跳过信息优先级 |
| 不给推荐，只给选项 | 用户被迫做他不该做的设计决策 |
| 首屏塞 6 个区块 | 等于没有主任务 |
